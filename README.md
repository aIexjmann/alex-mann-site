# Alex Mann website

A standalone copy of the public biography website, prepared September 25, 2026. All site assets are included. No build tools or installation are needed.

Open `index.html` to view the site. Edit the biography in `index.html`, the appearance in `styles.css`, and the photo in `portrait.jpg`.

## Publish separately with GitHub Pages

1. Create a new public repository in your GitHub account, such as `alex-mann-site`.
2. Upload this folder’s contents, keeping `index.html` at the repository root and preserving the `assets` folder.
3. Under Settings → Pages, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
4. GitHub will display the separate website address after publishing.

Leave the Custom domain field empty. This version intentionally has no CNAME file; publishing it will not move alexjmann.com or change its DNS settings.

The portrait was copied from the existing alexjmann.com website. Text and imagery remain the property of their respective owners. This copy has no dependency on the existing site’s hosting service.
